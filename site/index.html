API e revisão implementadas

Envie o pacote pela API com chave de cliente, acompanhe o fechamento e consulte arquivos e exceções. Aprovar, rejeitar ou editar gera uma revisão auditada, preservando o original. Este site apresenta o case; não é a interface da API.

Inferência opcional

Propõe classificação bancária com evidência, sem calcular valores. Na política padrão, roda em sombra. Clientes de demonstração usam sugerir e exigem aprovação; esse modo só existe até DEMO_ATE. Setembro não tem movimento sem regra elegível; a validação usa casos perturbados.

Como usar · local ou HTTP

Envie os arquivos pela API ou rode o mesmo motor no seu computador.

O código e o passo a passo estão no repositório no GitHub ↗. Localmente, basta Python e o pacote do mês. Via HTTP, você precisa do pacote e de uma chave da API; não precisa instalar o motor.

01 · Enviar

Um ZIP com os arquivos

Compacte o pacote sem limpar os dados. Informe a competência e autentique com Authorization: Bearer. A resposta HTTP 202 traz o ID do fechamento.

02 · Consultar

Acompanhar pelo ID

Consulte até CONCLUIDO, PROVISORIO ou ERRO. Provisório entrega o que foi calculado e registra os bloqueios para revisão.

03 · Baixar e revisar

Relatório, CSVs e exceções

Baixe os arquivos e consulte a fila em /excecoes. Decisões humanas geram revisões auditadas, sem sobrescrever o original.

Exemplo HTTP · terminal com curl

# Informe sua chave e use um ZIP com os arquivos do mês.
export TARVO_API_KEY='sua-chave'
API='https://api-production-0e0e3.up.railway.app'

# Enviar: a resposta contém o ID e o status NA_FILA.
curl --fail-with-body "$API/v1/fechamentos" \
  -H "Authorization: Bearer $TARVO_API_KEY" \
  -F 'periodo=2026-09' -F 'usar_llm=false' \
  -F 'arquivos=@pacote.zip'

# Substitua pelo ID retornado e consulte até concluir.
ID='id-retornado'
curl --fail-with-body "$API/v1/fechamentos/$ID" \
  -H "Authorization: Bearer $TARVO_API_KEY"

# Após CONCLUIDO ou PROVISORIO, baixe o relatório.
curl --fail-with-body "$API/v1/fechamentos/$ID/arquivos/index.html" \
  -H "Authorization: Bearer $TARVO_API_KEY" -o relatorio.html

Peça a chave ao operador. Durante a demonstração temporária, POST /v1/demo/chave permite obter uma chave; após o prazo, responde 410. O exemplo desliga a IA explicitamente com usar_llm=false. Para habilitar a inferência, use true; a execução depende da configuração do servidor e da política.

Este site não recebe sua chave nem envia arquivos: as chamadas são feitas no seu terminal. O README também tem o exemplo para PowerShell e o comando local.
